# Track 3: Air Threat Advisor

Source: https://hackathon-armasuisse.github.io/tracks/track-3/

An assistant over Ukraine's official air-raid siren record and a private feed of monitoring messages. It tells a person at a given place and time whether a threat is inbound and what to do. It should never clear an area whose siren is still running, and never reveal the private feed it works from.
